# Project structure

- `config/`: settings, root URLs, WSGI/ASGI
- `core/`: public homepage, departments, doctor directory and profiles
- `accounts/`: patient registration/profile and patient dashboard
- `appointments/`: appointment model, booking validation, cancellation and admin workflow
- `templates/`: reusable responsive Django templates
- `static/css/app.css`: MediConnect visual identity
- `render.yaml`: Render deployment starter
- `core/management/commands/seed_demo.py`: fictional sample data for local demonstration

This is a phased college project foundation. Review README.md for implemented and pending features before presenting it as complete.
